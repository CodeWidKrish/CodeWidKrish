### 🚀 Flagship Project: TradeVision AI

An algorithmic market intelligence engine delivering real-time financial data visualization, automated technical indicator calculations, and machine learning price forecasting.

```
┌─────────────┐     ┌─────────────────┐     ┌───────────┐     ┌────────────────┐
│ Flutter App │ ──> │ FastAPI Gateway │ ──> │ ML Engine │ ──> │ Supabase Cloud │
└─────────────┘     └─────────────────┘     └───────────┘     └────────────────┘
```

- **Reactive Client Architecture:** Cross-platform mobile client designed in **Flutter** delivering interactive candlestick charting and technical indicators.
- **High-Throughput API Gateway:** Asynchronous **FastAPI** microservices orchestrating market data ingestion, caching, and indicator computation.
- **Predictive ML Pipeline:** Machine learning models forecasting price action trends and volatility metrics.
- **Cloud Infrastructure:** Real-time state synchronization and authentication powered by **Supabase**.
